## Commands Covered

### File Management
- `touch` — Create empty files.
- `mkdir` — Create directories.
- `cp` — Copy files and directories.
- `mv` — Move or rename files and directories.
- `rm` — Remove files.
- `rmdir` — Remove empty directories.

### Searching Files and Text
- `find` — Search for files and directories based on specified criteria.
- `grep` — Search for matching text patterns within files.
- `grep -i` — Search without case sensitivity.
- `grep -r` — Search recursively through directories.
- `locate` — Find files by name using an indexed database.
